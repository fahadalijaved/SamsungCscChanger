# # Samsung CSC Changer

A lightweight, hardware-level utility designed to interface with Samsung devices in DM (Diagnostic Mode) via serial communication to seamlessly update carrier configurations (CSC).

## 🚀 How to Download & Install

To install the latest version on your Android controller device:

1. Head over to the **[Releases](https://github.com/fahadalijaved/SamsungCscChanger/releases)** section on the right side of this page.
2. Download the latest `.apk` asset file (e.g., `SamCSC-Changer-v1.3.apk`).
3. Open the downloaded file on your device and follow the prompts to install it. *(Note: You may need to allow installation from unknown sources in your browser/file manager settings).*

---

## 🛠️ Requirements & Setup

* **Controller Device:** An Android device running the app with USB OTG support.
* **Target Device:** The Samsung phone you intend to modify.
* **Connection:** A reliable USB OTG cable or adapter connecting both devices.
* **Target Phone Setup:**
  * Ensure the target device is completely unlocked.
  * Keep the screen awake during the sequence execution.

---

## 📋 Features

* **Auto-Detection:** Automatic probing for supported USB-to-serial interfaces.
* **Manual Overrides:** Explicit overrides for device model strings and target CSC parameters.
* **Hardware Controls:** Direct options to bypass target register faults or force-reboot connected hardware into Odin Download Mode.
